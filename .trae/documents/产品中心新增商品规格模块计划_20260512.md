# 产品中心新增「商品规格」模块计划（基于 public_property_value）

## Summary
- 在左侧「产品中心」新增菜单「商品规格」
- 新增页面：左侧展示规格组（`public_property_name`），右侧维护该组下的规格值（`public_property_value`）
- 点击左侧规格组仅做“选中切换”；右侧点击“新增规格值”即可新增并自动关联当前规格组
- 不改数据库表结构：`public_property_value` 不新增“排序/状态”等字段；图片字段采用 URL + 预览

## Current State Analysis
- 数据库已有相关表结构（见 [init.sql](file:///Users/hvai/trae/crm-ai-v3.8/supabase/rebuild/init.sql#L156-L177)）：
  - `public_property_name`：规格组（`specification_name` / `group_name` / `image` / `is_searchable`）
  - `public_property_value`：规格值（`property_id` 外键 -> `public_property_name.id`，以及 `property_value`、`property_value_image`、`public_property_name` 文本冗余字段）
- 现有前端已实现「规格组」列表页（`spec-groups`），并已在 [productRepository.ts](file:///Users/hvai/trae/crm-ai-v3.8/src/lib/productRepository.ts) 中提供 `public_property_name` 的列表/保存/删除能力
- 通用弹窗组件 [DetailModal](file:///Users/hvai/trae/crm-ai-v3.8/src/components/DetailModal.tsx) 支持 `type: 'image'` 的 URL 输入 + 图片预览，满足规格值图片录入需求

## Proposed Changes

### 1) 新增前端类型
- 修改 [product.ts](file:///Users/hvai/trae/crm-ai-v3.8/src/types/product.ts)
  - 新增 `PublicPropertyValue`：
    - `id: string`
    - `propertyId: string`（对应 `property_id`）
    - `propertyValue: string`（对应 `property_value`）
    - `propertyValueImage?: string`（对应 `property_value_image`）
    - `publicPropertyName: string`（对应 `public_property_name`）
    - `createDate?: string`（`created_at`）
    - `updateDate?: string`（`updated_at`）

### 2) 仓库层：public_property_value CRUD + 辅助查询
- 修改 [productRepository.ts](file:///Users/hvai/trae/crm-ai-v3.8/src/lib/productRepository.ts)
  - 增加 `public_property_value` 映射：
    - `mapDbPublicPropertyValueToUi(row)`
  - 增加规格组下拉/侧边栏所需的“全量规格组”查询（避免分页取不全）：
    - `fetchPublicPropertyNamesFromSupabase()`：select `id, specification_name, group_name, is_searchable, image, created_at, updated_at`，按 `created_at asc / id asc` 排序
  - 增加规格值查询（按规格组过滤）：
    - `fetchPublicPropertyValueListFromSupabase(params)`
      - 入参：`propertyId`（必填）、`keyword?`（匹配 `property_value`）、`page`、`pageSize`
      - 排序：`created_at desc` + `id desc`
      - 返回：`PagedResult<PublicPropertyValue>`
  - 增加保存/删除：
    - `savePublicPropertyValueToSupabase(row: PublicPropertyValue)`
      - 新增：insert（不传 id）
      - 编辑：update by id
      - 写入规则：
        - `property_id` 固定为当前选中规格组 id
        - `public_property_name` 固定为当前选中规格组 `specification_name`（保证冗余字段一致）
        - `property_value` trim 后必填
        - `property_value_image` 使用 DetailModal 的 `image` 类型录入（URL 或上传转 base64）
        - `updated_at` 前端显式写 `new Date().toISOString()`
    - `deletePublicPropertyValueFromSupabase(id: string)`
  - ID 合法性校验：复用现有 `toNullableInt`

### 3) 新增页面：商品规格（左组右值）
- 新增文件：`src/pages/ProductSpecs.tsx`（组件名建议 `ProductSpecsPage`）
  - 页面布局（参考截图风格，按现有 Tailwind 组件写法实现）：
    - 顶部：标题「商品规格」+ 按钮「新增规格值」（无选中组时禁用并 toast 提示）
    - 主体：左右两栏
      - 左侧规格组栏：
        - 数据源：`fetchPublicPropertyNamesFromSupabase()`
        - 支持：规格组关键词过滤（前端过滤即可，避免额外 SQL）
        - 点击某组：仅切换“选中态”，刷新右侧规格值列表
      - 右侧规格值栏：
        - 数据源：`fetchPublicPropertyValueListFromSupabase({ propertyId })`
        - 支持：规格值关键词搜索 + 分页（与 Brands 页面一致的分页控件即可）
        - 表格列：
          - ID
          - 规格值（propertyValue）
          - 图片（propertyValueImage 缩略图）
          - 创建时间
          - 更新时间
          - 操作（查看/编辑/删除）
    - 弹窗（DetailModal）：
      - 新增/编辑规格值字段：
        - 规格值：`propertyValue`（required）
        - 图片：`propertyValueImage`（type: 'image'，URL+预览）
      - 规格组信息不在弹窗里可编辑（由当前选中组决定）
  - 用户提示：
    - 加载失败 toast.error
    - 保存/删除成功 toast.success
    - 未选择规格组时点击“新增规格值” toast.error 提示先选择

### 4) 菜单与路由接入
- 修改 [Sidebar.tsx](file:///Users/hvai/trae/crm-ai-v3.8/src/components/Sidebar.tsx)
  - 在「产品中心」新增：`{ id: 'product-specs', label: '商品规格', icon: ... }`

## Assumptions & Decisions
- 不新增数据库字段（不实现截图里的“排序/状态”真实落库）；列表仅按时间/ID 排序展示
- “点击左侧规格组”仅用于选中与切换右侧列表；新增动作统一从右侧按钮触发
- `public_property_value.public_property_name` 作为冗余字段，在保存时强制写入选中组的 `specification_name`，避免历史不一致
